Сначала включите безопасный DNS (Secure DNS).\n    * В Chrome включите пункт "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".\n    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.\n    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот способ рекомендуется.\n    * Владельцам роутеров Keenetic нужно включить параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.\n\n2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases/latest).\n\n3. Откройте свойства архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно пропустить.\n\n4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.\n\n5. Запустите подходящий файл.\n    * Чтобы подобрать рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.\n    * Для установки стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> выберите нужную стратегию.\n\n## ℹ️ Назначение файлов\n\n- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.\n\n  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**.\n\n- [**`service.bat`**](./service.bat) предназначен для установки автозапуска и дополнительных операций:\n  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>\n  - **`Remove Services`** удаляет стратегию и WinDivert из служб.\n  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.\n  - **`Game Filter`** переключает обход для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  \n  **После изменения настройки стратегию необходимо перезапустить.**  \n  Текущее состояние включения или выключения указано в скобках.\n  - **`IPSet Filter`** управляет обходом сервисов из `ipset-all.txt`.  \n  Это полезно при диагностике ресурса, который без zapret доступен, а с ним не работает.  \n  В скобках отображается текущий режим:\n    - `none` - IP-адреса не проходят проверку\n    - `loaded` - IP проверяется на наличие в списке\n    - `any` - под фильтр попадает любой IP\n  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.\n  - **`Replace active fakes`** заменяет используемый fake на другой файл из каталога `bin`.\n  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.\n  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>\n  - **`Check for Updates`** вручную проверяет наличие обновлений.\n  - **`Run Diagnostics`** ищет распространённые причины, из-за которых zapret может не запускаться или не работать.  \n  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.\n  - **`Run Tests`** запускает проверку стратегий:\n    - `Standard tests` проверяет сайты из `utils/targets.txt`\n    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon\n\n## ☑️ Частые вопросы и неисправности\n\n### После запуска `general*` ничего не появляется\n\nПри запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe, отвечающий за обход.  \nЕсли его нет, обратитесь к [#522](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/522).\n\n### Не удалось подобрать стратегию\n- Откройте командную строку с правами администратора.\n- Выполните команды по очереди:\n\n    `netsh winsock reset`\n  \n    `netsh int ip reset all`\n  \n    `netsh winhttp reset proxy`\n  \n    `ipconfig /flushdns`\n\n- Перезагрузите компьютер.\n\n### Не открывается Telegram в браузере\nЗапустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  \n  - Скопируйте весь текст из открытого блокнота.\n  - Откройте файл `hosts` в появившемся каталоге через текстовый редактор, запущенный от имени администратора.\n  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный блок.\n  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что файл действительно был сохранён.\n\n#### Результат не гарантируется. Если этот способ не сработал, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/PennantBladeChaos/tg-ws-proxy) или одним из публичных прокси.\n\n### Обход не запускается или больше не помогает\n\n> [!IMPORTANT]\n> **Стратегии могут со временем терять работоспособность.**\n> Вариант, который некоторое время работал, может перестать действовать после его обнаружения.\n> В этом репозитории собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.\n> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).\n\n- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.\n\n- Проверьте наличие адреса ресурса в списках доменов или IP-адресов.\n\n- Попробуйте другие варианты, включая **`ALT`** и **`FAKE`**.\n\n- Выполните полную переустановку по инструкции ниже.\n\n- Дополнительные сведения: [#765](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/765).\n\n### Как полностью обновить или переустановить проект?\n- Сохраните добавленные вами ресурсы и другие данные.\n- Перезапустите устройство.\n- Выполните `service.bat` -> `Remove Services`.\n- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y.\n- Удалите старую папку zapret.\n- Загрузите свежую версию [со страницы релизов](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases), файл `zapret-discord-youtube-...`.\n- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и затем "ОК".\n- Распакуйте архив в новую папку в корне диска, избегая пробелов, специальных символов и кириллицы в пути.\n- Поочерёдно попробуйте разные скрипты `general`. После каждой проверки открывайте нужные интернет-ресурсы. Если они недоступны, закройте программу через значок замка в панели задач и запустите другую стратегию.\n- Найдя рабочий вариант, установите его в автозапуск через `service.bat` -> `Install Service`.\n\n### Игра или приложение не работает при включённом zapret\n\n- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.\n\n### Античит обнаруживает WinDivert\n\n- Изучите инструкцию в репозитории https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.\n\n### В Windows 7 требуется цифровая подпись драйвера WinDivert\n\n- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).\n\n### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб\n\n1. Найдите имя службы в командной строке Windows, открытой через Win+R и `cmd`:\n\n```cmd\ndriverquery | find "Divert"\n```\n\n2. Остановите и удалите найденную службу:\n\n```cmd\nsc stop название_из_первого_шага\n\nsc delete название_из_первого_шага\n```\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube\n\n- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).\n- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.\n- Переберите остальные стратегии, особенно если раньше всё работало.\n- См. также [#251](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/251).\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord\n\n- Проверьте, включён ли [Secure DNS](#%EF%B8%8F-использование).\n- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.\n- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.\n- Снова проверьте приложение Discord.\n- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, используйте её.\n- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.\n- См. также [#252](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/252).\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram\n\n- Воспользуйтесь [tg-ws-proxy](https://github.com/PennantBladeChaos/tg-ws-proxy).\n- Либо подключите бесплатный MTProto-прокси, найденный в интернете.\n\n### Не работают игры\n\nИгр много, поэтому проверить и исправить каждую из них невозможно.\n\nНачните с универсального варианта:\n- через `service.bat` обновите ipset и включите `Game Filter`;\n- если результата нет, дополнительно включите режим `ipset any`.\n\nУчитывайте, что `ipset any` может нарушить доступ ко многим сайтам. Не держите этот режим включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.\n\nЕсли это тоже не помогло, создайте обсуждение в разделе [Discussions](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.\n\n### В списке нет моей проблемы\n\n- Создайте обращение [здесь](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues).\n\n## 🗒️ Добавление адресов других ресурсов\n\nСписок ресурсов для обхода можно дополнить следующими файлами:\n- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.\n- **`list-exclude-user.txt`** - домены, которые нужно исключить. Это пригодится, например, когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется.\n- **`ipset-all.txt`** - IP-адреса и подсети.\n- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключаемые из обработки.\n  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.\n\n## ⭐ Поддержка проекта\n\nПоддержать проект можно, поставив :star: этому репозиторию в правом верхнем углу страницы.\n\nМатериально поддержать оригинального разработчика zapret можно [здесь](https://github.com/bol-van/zapret?tab=readme-ov-file#%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0).\n\n## ⚖️ Лицензия\n\nПроект распространяется по лицензии [MIT](https://github.com/PennantBladeChaos/zapret-discord-youtube/blob/main/LICENSE.txt).\n\n## 🩷 Участники проекта\n\n[![Contributors](https://contrib.rocks/image?repo=PennantBladeChaos/zapret-discord-youtube)](https://github.com/PennantBladeChaos/zapret-discord-youtube/graphs/contributors)\n\n💖 Особая благодарность автору [zapret](https://github.com/bol-van/zapret) - [bol-van](https://github.com/bol-van)
